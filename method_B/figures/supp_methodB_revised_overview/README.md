# Revised Method B supplementary overview

Run from this directory:

```bash
python methodB_supp_revised_figure/make_supp_methodB_revised_figure.py
```

This folder keeps the original relative layout expected by the script:

- `methodB_supp_revised_figure/` contains the main script and final outputs.
- `v_apex_scores/methodB_scatter_best_assay_specific/` contains the compact plot-data and validation tables.
- `fig_cutoff_derivation_thresholds.csv` is the cut-off table used by the overview.
- `fit_vplot_apex.py` is included for fallback recomputation, although the cached real apex-likelihood profile is already present.

Final outputs:

- `methodB_supp_revised_figure/supp_methodB_revised_overview.png`
- `methodB_supp_revised_figure/supp_methodB_revised_overview.pdf`
- `methodB_supp_revised_figure/supp_methodB_revised_overview.svg`
